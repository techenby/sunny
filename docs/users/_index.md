# User Guides

These guides explain how to use Sunny's household features.

- [Routines](/docs/users/routines): Create repeating checklists and complete
  scheduled steps from a kiosk.
- [Lists and Checklists](/docs/users/checklists): Keep shared to-do, shopping,
  and wish lists up to date.
- [Recipes](/docs/users/recipes): Build a cookbook, import recipe pages, and
  share recipes by link or with another team.
- [Inventory](/docs/users/inventory): Organize belongings by location, bin, and
  item, with photos, metadata, and QR codes.
- [Teams and Households](/docs/users/teams): Switch workspaces, invite people,
  and understand team roles.
- [Set Up a Kiosk](/docs/users/kiosk/getting-started): Pair a shared display
  with a household.
- [Calendar Feeds](/docs/users/kiosk/calendar-feeds): Add events from Proton
  Calendar or Google Calendar to a kiosk.
