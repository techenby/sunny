# Lists and Checklists

Sunny calls checklists **Lists** in the navigation. Lists remain available
until someone updates them, which makes them useful for groceries, errands,
wish lists, and other shared collections.

Lists belong to the current team and are shared with everyone on that team.
Assigning a list to a person helps the household see who it belongs to, but
does not make it private or prevent another team member from updating it.

## Create a list in the main app

1. Open **Lists** from the main sidebar.
2. Select **Add List**.
3. Enter a name and choose **To-do**, **Shopping**, or **Wish List**. The type
   supplies a recognizable label and icon; all three work the same way.
4. Set **Belongs to** to the whole **Household** or to a specific team member.
5. Select **Create**.
6. Add items using the field at the bottom of the list.

Tap an item to check or uncheck it. Sunny records who checked it and shows
their name beside the completed item. Use the trash button beside an item to
remove it.

Once a list contains completed items, its menu provides two cleanup options:

- **Uncheck all** keeps every item and makes the whole list active again.
- **Clear completed** permanently removes only the checked items.

From the Lists overview, use a list card's menu to edit its name, type, or
owner; open its items; or delete the entire list.

## Use a list on a kiosk

After [setting up a kiosk display](/docs/users/kiosk/getting-started), select
**Lists** in the kiosk sidebar. Use the list buttons across the top to switch
between the team's lists.

- Add an item with the input at the top of the selected list.
- Tap an item to check or uncheck it.
- Use the **×** button to remove an item.
- Select **Clear completed** to remove all checked items from the selected list.

The kiosk can update list items, but it cannot create or delete an entire list
or change a list's name, type, or owner. Make those changes from the main app.
If the team has no lists yet, the kiosk directs you back to Sunny on a phone or
computer to create one.
