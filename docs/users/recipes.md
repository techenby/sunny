# Recipes

Recipes are stored in the current team's cookbook. Everyone on the team can
use the same collection, while another team has its own cookbook.

## Add a recipe

1. Open **Recipes** from the main sidebar.
2. Select **Add Recipe**.
3. Enter a name and any details you want to keep, such as servings, prep time,
   cook time, ingredients, instructions, notes, nutrition, and tags.
4. Optionally add a JPG or PNG photo up to 5 MB.
5. Select **Create Recipe**.

Only the name is required. You can return later and use **Edit** from the
recipe menu to fill in or change the other fields.

## Import from a website

On the Add Recipe or Edit Recipe screen, paste a recipe URL into **Source** and
select the import button at the end of the field. Sunny fills the fields it can
read from the page.

> [!IMPORTANT]
> Review the imported ingredients, instructions, times, and servings before
> saving. Recipe websites format their pages differently, so some information
> may be missing or need cleanup. You can still enter the recipe manually if
> importing fails.

The Source field can also contain plain text, such as the name of a cookbook
or the person who shared the recipe.

## Find and organize recipes

The Cookbook screen lets you search by recipe name and sort the Name column.
It also shows each recipe's source and total time when available.

Open a recipe to see its complete details. Its menu provides these actions:

- **Remix** creates a separate copy in the same cookbook with “(Remix)” added
  to its name. Edit the copy without changing the original.
- **Copy to Team** copies the recipe into another team you belong to.
- **Edit** updates the recipe.
- **Delete** removes the recipe from the cookbook.

## Share a recipe by link

1. Open the recipe and choose **Share** from its menu.
2. Turn on **Public Link**.
3. Copy the generated link and send it to the person who needs it.

Anyone with the link can view the recipe without joining your team. A signed-in
Sunny user can select **Add to My Team** to save a copy in their current
cookbook.

Turn **Public Link** off when the link should stop working.

> [!WARNING]
> A public recipe link is not access-controlled. Do not include private
> information in a recipe you share publicly.
